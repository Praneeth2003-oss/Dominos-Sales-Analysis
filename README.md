# 🍕 Domino's Pizza Sales Analysis

## 📊 Project Overview

This project focuses on analyzing **Domino's Pizza sales data** to understand overall sales performance, customer ordering patterns, and product performance.

The project uses **SQL** to analyze pizza sales data and calculate important business metrics. The analysis covers sales trends, pizza categories, pizza sizes, order patterns, and individual pizza performance.

The results are presented through a **Tableau-style dashboard** that provides a simple and visual way to understand the overall performance of the business.


## 🎯 Project Objectives

- Analyze overall pizza sales performance
- Calculate key business KPIs such as revenue, orders, and pizzas sold
- Identify the best and worst-performing pizzas
- Analyze sales by pizza category
- Analyze sales by pizza size
- Understand monthly order trends
- Analyze order volume by day of the week
- Identify popular pizza categories and sizes
- Present the analysis through an easy-to-understand dashboard


## 🛠️ Tools & Technologies

- **MySQL** – Used for database management and SQL analysis
- **SQL** – Used for data querying, aggregation, filtering, grouping, and ranking
- **Tableau** – Used for data visualization and dashboard creation
- **GitHub** – Used for project documentation and version control
